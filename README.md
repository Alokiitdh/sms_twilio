# SMS / WhatsApp Notification Service with Twilio

A lightweight Python project managed with [`uv`](https://github.com/astral-sh/uv) to send programmatic messages using the Twilio API.

---

## Features

- Fast virtual environment and package management via `uv`
- Secure environment configuration using `python-dotenv`
- Supports SMS and WhatsApp messaging via Twilio

---

## Prerequisites

- [Python](https://www.python.org/) 3.10+
- [`uv`](https://docs.astral.sh/uv/) package manager
- A [Twilio Account](https://www.twilio.com/) with an active Account SID and Auth Token
